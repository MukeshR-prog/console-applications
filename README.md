## ▶️ How to Run

1. Clone the repository

   ```bash
   git clone <your-repo-link>
   ```
2. Navigate to the project folder
3. Compile the Java file

   ```bash
   javac FileName.java
   ```
4. Run the program

   ```bash
   java FileName
   ```
